# USB to AES3 perfboard workshop

A modular USB-to-AES3 prototype built around the XMOS XU316 and Cirrus Logic CS8406. The project includes five perfboard layouts, wiring guides, and a combined OpenSCAD assembly.

- [Project overview](00_project_assembly.md)
- [Interactive viewer setup](viewer/README.md)

Run `node viewer/serve.mjs` and open [the local workshop](http://127.0.0.1:4173/) to view the guides and models side by side.
